# Ankit portfolio

A personal portfolio showcasing Ankit Maurya’s work and background in data science, AI/ML, and entrepreneurship.

The site presents his projects, education, and professional profile. It includes individual project pages, project visuals, and navigation. Visitors can also adjust and save theme and motion preferences.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
